# Spraygun archive

These launchers preserve the pre-AuthTempo project name for historical reference. They are not installed by the AuthTempo package and should not be used for new runs.

- `spraygun.py` forwards source-tree invocations to AuthTempo and prints the compatibility warning.
- `spraygun.sh` is the disabled historical shell prototype; it cannot invoke an authentication engine.

Use `authtempo` or `python3 authtempo.py` from the repository root.
